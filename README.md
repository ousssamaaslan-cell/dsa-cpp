# dsa-cpp
Basic data structures in C++

## Build on this Windows computer

From PowerShell, Command Prompt, or Git Bash, run `cpp-build path/to/file.cpp`.
For example, `cpp-build "control structures/hello.cpp"` creates
`%USERPROFILE%\.local\bin\hello.exe`; then run `hello` by name from any of
those terminals. Rebuild after editing the source file. In VS Code,
`Ctrl+Shift+B` builds the open C++ file to the same executable folder.
